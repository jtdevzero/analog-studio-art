# Analog Studio Art – egyesületi irányítópult

**Megnyitás:** https://jtdevzero.github.io/analog-studio-art/

Projektek, feladatok, ütemterv, pályázatok, partnerek, workshopok, kommunikáció, tagok, eszközök és pénzügyek egy helyen az Analog Studio Art Egyesületnek.

Az oldal nyilvános, az adatok nem: belépéskor egy hozzáférési kulccsal egy privát repóból tölti be és oda menti őket. Claude-fiók nem kell hozzá.

## Belépés
- A vezetőségtől kapott **belépési linkkel** (egy kattintás, utána az eszköz megjegyzi).
- Vagy a hozzáférési kulcs beírásával.
- Új vezető hozzáadása: belépés után az oldalsávban **Link küldése**.
- Kilépés: oldalsáv → **Kilépés** (mobilon: Több → Kilépés).

## Biztonság
Aki megkapja a linket vagy a kulcsot, olvashatja és szerkesztheti az adatokat, amíg a kulcsot vissza nem vonják (GitHub → Settings → Developer settings → Fine-grained tokens). Ezért csak megbízható vezetőknek küldd el.
